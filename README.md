## 🚀 Getting Started

### Run it locally — no setup required!

```bash
# 1. Clone the repository
git clone https://github.com/PriyadharshiniChandrasekar/My-OOPsLearningWeb.git

# 2. Open the folder
cd My-OOPsLearningWeb

# 3. Just open index.html in your browser 🎉
```

That's it — no build tools, no npm install, no server needed.

### 🌐 Live Demo

Enable **GitHub Pages** for this repo (Settings → Pages → Branch: `main`) and your site goes live at:

```
https://priyadharshinichandrasekar.github.io/My-OOPsLearningWeb/
```
