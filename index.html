Java OOPS: The Four Pillars

Object-Oriented Programming (OOPs) is a paradigm that structures programs around data and objects, rather than logic and functions. It helps in making code modular and reusable.

Brief Explanation of the 4 Pillars:

  • Inheritance: Creating new classes from existing ones (Reusability).
  • Polymorphism: One interface, multiple methods (Flexibility).
  • Encapsulation: Binding data and methods together (Security).
  • Abstraction: Hiding complexity and showing only functionality (Simplicity).

1. Class & Object

A Class is a template or blueprint. An Object is a physical entity created from that blueprint.

Real-Time Example:

A "Car Design" on paper is the Class. The "BMW Car" parked in your garage is the Object.

// Full Java Program for Class & Object class Car { String brand; int speed; void drive() { System.out.println(brand + " is driving at " + speed + " km/h"); } } public class Main { public static void main(String[] args) { // Creating an Object of Car Car myCar = new Car(); myCar.brand = "Toyota"; myCar.speed = 100; myCar.drive(); // Calling method } }

2. Constructor

A Constructor is a special method used to initialize objects. It is called automatically when an object is created.

Real-Time Example:

When you sign up for a new Email Account, the system automatically assigns you a default storage space. That "initial setup" is done by a constructor.

// Full Java Program for Constructor class Student { String name; // Parameterized Constructor Student(String studentName) { name = studentName; System.out.println("New student record created for: " + name); } void display() { System.out.println("Hello " + name); } } public class Main { public static void main(String[] args) { Student s1 = new Student("Aryan"); // Automatic call s1.display(); } }

3. Encapsulation

Encapsulation involves wrapping data (variables) and code (methods) together and keeping them safe from outside interference.

Real-Time Example:

A School Bag. Your books and pens are inside, and you decide who can take them out. In Java, we use private variables and getter/setter methods.

// Full Java Program for Encapsulation class Laptop { private String password; // Private variable // Setter public void setPassword(String p) { this.password = p; } // Getter public void showPassword() { System.out.println("Laptop Password is: " + password); } } public class Main { public static void main(String[] args) { Laptop myLap = new Laptop(); myLap.setPassword("Admin@123"); myLap.showPassword(); } }

4. Inheritance

Inheritance allows one class to acquire properties and methods of another class using the extends keyword.

Real-Time Example:

A Son inheriting property or eye color from his Father.

// Full Java Program for Inheritance class Animal { void eat() { System.out.println("This animal eats food."); } } class Dog extends Animal { void bark() { System.out.println("The dog barks loudly."); } } public class Main { public static void main(String[] args) { Dog d = new Dog(); d.eat(); // Inherited method d.bark(); // Own method } }

5. Polymorphism

Polymorphism means performing a single action in different ways. In Java, this is achieved by Overloading and Overriding.

Real-Time Example:

The "+" Operator. When used with numbers (2+2), it gives 4. When used with strings ("Hello"+"World"), it joins them. Same operator, different behavior!

// Full Java Program for Runtime Polymorphism class Shape { void draw() { System.out.println("Drawing a shape..."); } } class Circle extends Shape { void draw() { System.out.println("Drawing a Circle..."); } } public class Main { public static void main(String[] args) { Shape s = new Circle(); // Parent reference, child object s.draw(); // Calls Circle's draw() } }

6. Abstraction

Abstraction hides the complex internal logic and only shows the necessary functionality to the user.

Real-Time Example:

Driving a Car. You know that pressing the brake stops the car, but you don't need to know the hydraulic pressure or internal engine mechanics to drive.

// Full Java Program for Abstraction abstract class Bank { abstract void interestRate(); // Abstract method } class SBI extends Bank { void interestRate() { System.out.println("SBI Interest Rate: 7%"); } } public class Main { public static void main(String[] args) { Bank myBank = new SBI(); myBank.interestRate(); } }
